# Repository Guidance

## Project context

This repository is currently a minimal portfolio project containing only `README.md`. Treat the README and any files added later as the source of truth for the project's purpose, content, and technology choices. Do not assume a framework, build system, or deployment target unless the repository establishes one.

## Working in this repository

- Keep changes focused on the requested task and consistent with the existing project structure.
- Prefer straightforward, readable solutions suitable for a student portfolio project.
- Avoid introducing dependencies, frameworks, generated files, or configuration unless the task calls for them.
- Preserve existing content and conventions when extending the portfolio; do not invent personal details, project history, or claims.
- Keep filenames and links clear, and check that referenced local assets use paths that match their actual locations.

## Portfolio content and presentation

- Make content easy to scan and use clear headings and concise descriptions.
- Use semantic structure and accessible language. For web content, provide useful alternative text for meaningful images and ensure links describe their destination.
- Keep visual and technical choices consistent across pages as the project grows.

## Verification

- First inspect the files and available scripts relevant to the change.
- Use the repository's documented commands when available; do not assume a command exists if there is no project configuration for it.
- For content-only edits, review the changed text and links for accuracy and consistency.
